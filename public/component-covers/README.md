# Component cover images

Drop a cover image for each component type here. The Components gallery picks it up automatically.

## Naming

Use the component slug as the filename:

```
public/component-covers/button.webp
public/component-covers/dialog.png
public/component-covers/table.jpg
```

Supported extensions: `.webp`, `.png`, `.jpg`, `.jpeg`, `.svg`

## Recommended size

- Aspect ratio: **16:10** (same family as system covers)
- Suggested: **1280 × 800**
- Keep the component UI readable and centered; avoid tiny crops

## Slug reference

Common slugs: `accordion`, `alert`, `avatar`, `badge`, `breadcrumb`, `button`, `button-group`, `card`, `checkbox`, `combobox`, `command`, `date-picker`, `dialog`, `drawer`, `dropdown-menu`, `empty-state`, `file-upload`, `form`, `header`, `link`, `list`, `navigation`, `pagination`, `popover`, `progress`, `radio`, `search`, `segmented-control`, `select`, `skeleton`, `slider`, `spinner`, `table`, `tabs`, `text-input`, `toast`, `toggle`, `tooltip`, `tree-view`, `wizard`

Until a file is uploaded, the gallery shows a visual placeholder for that component.
